# ✈️ Gestion de Réservation de Billets d'Avion

Application de bureau développée en **C++** avec le framework **Qt** et une base de données **MySQL**.

## 📌 Structure du projet

- `docs/` : dossier de conception (UML, MCD, MLD, ...)
- `database/` : scripts SQL pour la base de données MySQL.
- `src/` : code source C++ et interfaces graphiques Qt.

## 🛠️ Technologies

- **Langages** : C++, SQL
- **Framework** : Qt 6
- **SGBD** : MySQL
- **Conception** : MERISE (Looping), UML
